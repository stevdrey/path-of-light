# Assets and release

The code, addon, font and other assets have distinct licenses. Review [README licensing](https://github.com/stevdrey/path-of-light/blob/main/README.md) and sound credits; provenance and redistribution for some visual and generated audio assets remain unresolved. Inventory and clear or replace assets before distribution.

Choose supported OS and browser versions and record real-device checks for controls, accessibility, save/reload, audio, performance, browser storage and hosting. Godot web export requirements and any server configuration must be verified for the actual build. No release date or platform support is established by this page.
