# Assets and release

The code, addon, font and other assets have distinct licenses. Review [README licensing](https://github.com/stevdrey/path-of-light/blob/main/README.md), [sound credits](https://github.com/stevdrey/path-of-light/blob/main/assets/sounds/CREDITS.md), and the [asset provenance audit](https://github.com/stevdrey/path-of-light/blob/main/docs/asset-provenance-audit.md). Provenance and redistribution for visual assets and some audio remain unresolved. Clear or replace assets before distribution and review the exact release build.

Choose supported OS and browser versions and record real-device checks for controls, accessibility, save/reload, audio, performance, browser storage and hosting. Godot web export requirements and any server configuration must be verified for the actual build. No release date or platform support is established by this page.
