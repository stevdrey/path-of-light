# Level authoring

For each proposed level document its teaching purpose, main route, optional secret, hazards, checkpoint and recovery positions, exit and audiovisual cues. Introduce a new idea safely, then combine it; preserve a solo solution and test the same route in co-op. Check player, terrain and hazards at actual size and without relying on color or sound alone. Measure smooth and first-attempt time separately. Record build, evidence and unresolved defects; the four-level slice must be evaluated before expanding the campaign.
