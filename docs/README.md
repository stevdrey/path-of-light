# Project documentation

The [GDD](../GDD.md) is the provisional design source. [Roadmap](ROADMAP.md) records sequencing and gates; [backlog](backlog/README.md) records the planned work. [Wiki source](wiki/Home.md) contains contributor guidance. [Architecture decisions](adr/README.md) distinguish proposals from accepted decisions.

The [asset provenance audit](asset-provenance-audit.md) inventories the current baseline and tracks outstanding clearance and replacement actions.

The [existing-level measurement baseline](level-measurement-baseline.md) records reported observations, technical checks and outstanding limitations for E01-01.

The [import and integration-test baseline](import-test-baseline.md) records clean-import comparisons, commands and test results for E01-03.

All project documentation, issues, pull requests and agent instructions are in English. Player-facing language is a separate design decision: the GDD starts with Spanish.
