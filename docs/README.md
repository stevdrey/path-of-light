# Project documentation

The [GDD](../GDD.md) is the provisional design source. [Roadmap](ROADMAP.md) records sequencing and gates; [backlog](backlog/README.md) records the planned work. [Wiki source](wiki/Home.md) contains contributor guidance. [Architecture decisions](adr/README.md) distinguish proposals from accepted decisions.

All project documentation, issues, pull requests and agent instructions are in English. Player-facing language is a separate design decision: the GDD starts with Spanish.
