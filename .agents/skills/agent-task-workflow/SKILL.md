# Agent task workflow

Read AGENTS.md, the GDD, relevant roadmap, ADR, issue, existing scenes, scripts and tests. Identify goals, non-goals, dependencies, acceptance criteria and risks before editing. Separate implemented behavior from proposed design. Reuse evidence while it remains valid.

Implement the smallest coherent change. Use Godot-specific skills and editor tooling where available. Run focused tests, then broader checks when the affected boundary warrants them. Record exact commands, engine version and results; visual, audio, controller, accessibility and co-op behavior need appropriate human observation. Protect user data, asset rights and unrelated work. Document consequential decisions and limitations. Remote actions require the user's authorization; do not merge unless requested.
